# PashuRakshak Hackathon Demonstration Guide

This directory contains pre-seeded assets and the master end-to-end demonstration automation script for Smart India Hackathon (SIH) judges.

## Directory Contents
- `run_e2e_demo.py`: Master automated CLI presentation script connecting all 5 stages of the platform.
- `seed_animals.json`: 24 physiologically-simulated cattle profiles across 6 Maharashtra districts with 7-day vitals trends.
- `sample_clips/`: 4 behavioral video frames capturing healthy herd grazing, prolonged lying, limping gait, and isolation.
- `generate_demo_assets.py`: Reproducible asset generation script using the Digital Twin simulator.

## Running the Live Demo
```bash
python run_e2e_demo.py
```
